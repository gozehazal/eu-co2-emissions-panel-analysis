
# Understanding CO₂ Emission Drivers Across EU Countries

A quantitative research project examining factors associated with variation in CO₂ emissions across 27 European Union countries from 2018 to 2021.

## Research Overview

This project explores relationships between CO₂ emissions and socioeconomic and energy-related indicators, including economic development, renewable energy and urbanisation.

## Methods

- Data cleaning and exploratory analysis in R
- Panel-data regression and statistical diagnostics
- Fixed-effects modelling
- Analysis and visualisation of emissions-related indicators

## Repository Contents

- `analysis.Rmd` — R Markdown source code and analysis
- `final-report.pdf` — Final research report
